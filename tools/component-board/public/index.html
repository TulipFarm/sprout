How this board works
  • PICK starts paid work. Moving a card to PICK starts a local Copilot build with Opus 5.5.
  • Max 5 builds. Up to 5 picked cards build at once, directly in the main Sprout checkout. Watch them live on port 4321.
  • Checks one at a time. Typecheck, build and tests run for one card at a time.
  • You decide DONE. Finished builds land in REVIEW. Only you can mark a card DONE.
  • Full Cloud coverage. A build reaches REVIEW only after it covers every Cloud usage: variants, sizes, combinations, and features.
  • Sprout only. Components are delivered in Sprout. Cloud stays read-only and is not migrated. No commits or pushes are made.
  • No mouse needed. Every move has a named button. Drag and drop is optional.
